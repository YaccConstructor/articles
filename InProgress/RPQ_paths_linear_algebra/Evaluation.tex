We evaluate the reachability semantics (Boolean semiring instantiation) on real-world knowledge graphs.
The experiments are designed to answer the following research questions:

\begin{itemize}
	\item \textbf{RQ1:} How does our implementation compare with existing linear algebra-based RPQ solutions?
	\item \textbf{RQ2:} How does our implementation compare with production graph database systems?
	\item \textbf{RQ3:} What is the performance behavior across different query types and graph structures?
\end{itemize}

Experiments are conducted on a work station with Ryzen 9 7900X 4.7 GHz 12-core, 128 Gb of DDR5 RAM and running Ubuntu 22.04.

\subsubsection{Competitors}

We compare the performance of the proposed semiring-based LARPQ algorithm against state-of-the-art graph database management systems and other linear algebra-based approaches.
\begin{itemize}
    \item \textbf{MillenniumDB} \cite{!!!}: a persistent, open-source graph database with state-of-the-art RPQ performance.
    \item \textbf{FalkorDB} \cite{!!!}: an in-memory property-graph database using GraphBLAS.
    \item \textbf{LARPQ} \cite{!!!}: our linear-algebra-based RPQ evaluation algorithm.
\end{itemize}

Experimental results will be presented here. Based on preliminary findings from our earlier work \cite{!!!}, we expect the following:

\begin{itemize}
	\item The proposed algorithm should demonstrate significant speedups over existing linear algebra-based solutions (RPQ-matrix) on complex queries involving Kleene star operators;
	\item The algorithm should achieve comparable or better performance than MillenniumDB on reachability queries;
	\item Performance should be competitive with FalkorDB while supporting a broader class of regular path queries.
\end{itemize}

Detailed experimental results including:
\begin{itemize}
	\item Tables comparing execution times, memory consumption, and timeout rates;
	\item Scatter plots showing per-query performance distributions;
	\item Analysis of performance across different query types (simple patterns vs. Kleene star, Cypher-compatible vs. non-compatible);
	\item Scalability experiments on larger graphs.
